> 適合需要「穩重、專業、耐看」的設計場景。

## T1 · Pentagram / Michael Bierut

**哲學核心**：字體即語言，負空間即思想。設計的力量來自克制，而非堆疊。

**視覺 DNA**
- 色彩：黑白 + 1 個品牌色，絕不超過 3 色
- 字體：Helvetica Neue、Univers 或現代等線體；字體層級嚴格
- 佈局：瑞士網格系統，數學性留白（60%+ 空白率）
- 質感：平面、無陰影、無漸層

**最適場景**：品牌識別系統、企業年報、高端發表物料

**避免場景**：需要情感溫度的場景（兒童、醫療親民感）、需要豐富視覺層次的場景

**提示詞模板**
```
Pentagram / Michael Bierut style:
- Extreme typographic hierarchy, Helvetica Neue or Univers
- Swiss grid, mathematical whitespace (60%+ ratio)
- Monochrome + one accent color only
- Zero decoration — type and grid carry all visual weight
- Negative space as primary design element
```

## T2 · Müller-Brockmann — 瑞士網格純粹主義

**哲學核心**：網格不是限制，是自由的結構。所有元素在網格內找到它的位置，設計才有客觀的秩序。

**視覺 DNA**
- 色彩：單色或雙色，輔以純黑、純白
- 字體：Akzidenz-Grotesk、Helvetica；嚴格的字體模組
- 佈局：可見或不可見的網格柱，元素嚴格對齊
- 特徵：大膽的幾何圖形作為主視覺，文字與圖形比例精算

**最適場景**：資訊圖表、資料密集的簡報、海報設計、系統性文件

**避免場景**：需要有機感、溫暖感、不規則美學的場景

**提示詞模板**
```
Müller-Brockmann / Swiss International Style:
- Strict modular grid, all elements mathematically aligned
- Geometric shapes as primary visuals (circles, rectangles, diagonals)
- Akzidenz-Grotesk or Helvetica, limited weights
- Flat primary colors (red, black, yellow) on white
- Information hierarchy through scale and position, not decoration
```

## T3 · Kenya Hara — 空的設計

**哲學核心**：設計的本質是「空」（emptiness）。留白不是沒有東西，而是充滿可能性的空間。用最少表達最多。

**視覺 DNA**
- 色彩：白、米白、極淺灰；偶爾一個極度克制的重點色
- 字體：極細的無襯線體或細明體；字距寬鬆
- 佈局：大量留白，元素稀疏但每個位置都是決定
- 質感：紙張感、霧面、幾乎無陰影

**最適場景**：高端品牌官網、奢侈品、日系產品介紹、極簡美學空間

**避免場景**：需要資訊密度高的場景、需要能量與動感的場景

**提示詞模板**
```
Kenya Hara / Muji aesthetic:
- Extreme whitespace, paper-like warmth (#FAFAF7 background)
- Ultra-light typefaces, wide letter-spacing
- Single focal element, everything else recedes
- Colors: white, off-white, warm gray — one muted accent at most
- Emptiness as the primary design material
```

## T4 · Takram — 日式思辨設計

**哲學核心**：設計是連結技術與人性的橋樑。精密的系統思維 + 細膩的感性觸覺，二者不妥協。

**視覺 DNA**
- 色彩：深色系為主（深藍、炭灰）或明亮系統色，高對比
- 字體：精選的現代等線體，搭配 Mono 字體作為技術感點綴
- 佈局：系統化、模組化，但有人工調整的細節
- 質感：精緻的微陰影、細線條、資料可視化元素

**最適場景**：科技產品介紹、系統設計文件、工具類 App 原型、設計研究呈現

**避免場景**：輕鬆娛樂場景、需要大量情緒表達的場景

**提示詞模板**
```
Takram design philosophy:
- Systems thinking meets human sensitivity
- Dark mode preferred (#0F1117 or #1A1D2E base)
- Precise grid with intentional micro-adjustments
- Data visualization as poetry — charts feel crafted, not generated
- Mono typeface accents for technical credibility
- Subtle depth: 1px borders, soft glows, never harsh shadows
```

## T5 · Information Architects — 內容優先

**哲學核心**：真正的設計讓自己消失。當使用者只看到內容、感覺不到設計的存在，設計才成功。

**視覺 DNA**
- 色彩：黑字白底，標準連結藍（#0000EE 或接近值）
- 字體：系統字體優先（SF Pro、Roboto、Inter）；可讀性第一
- 佈局：單欄為主，66 字元行寬，呼吸感充足
- 特徵：無裝飾、無漸層、無動畫噱頭；效能即美學

**最適場景**：閱讀導向工具、技術文件、內容管理系統介面、長文閱讀頁

**避免場景**：需要視覺震撼、品牌個性強烈、需要吸引注意力的場景

**提示詞模板**
```
Information Architects / iA Writer philosophy:
- Content-first, zero decorative elements
- System fonts (Inter, SF Pro, Roboto) — no custom fonts
- Single column, 66-character line length
- Black on white, standard link blue, no hover effects beyond underline
- Progressive disclosure — depth revealed by reading, not scrolling
```

## T6 · Fathom Information Design — 科學敘事

**哲學核心**：每個像素都必須承載資訊。科學期刊的嚴謹，加上設計的優雅——二者不應是對立的。

**視覺 DNA**
- 色彩：冷靜的專業色調（深灰、海軍藍、石板色），一個資料重點色
- 字體：GT America、Graphik 或 Inter；嚴格的層級系統
- 佈局：資訊密度高但不壅塞；注釋與圖說融入設計
- 特徵：精確的資料視覺化、時間軸、散點圖、流程圖

**最適場景**：數據報告、研究呈現、年度回顧、基金會 / 機構出版物

**避免場景**：需要情緒渲染、娛樂性強的場景

**提示詞模板**
```
Fathom Information Design style:
- Scientific precision meets editorial elegance
- Neutral palette: #2B2D42 dark, #8D99AE mid, one #EF233C accent
- GT America or Inter, strict typographic scale
- Charts and data viz as primary visual language
- Footnotes and annotations styled as first-class elements
- High information density without visual clutter
```

## T7 · Build — 當代極簡品牌

**哲學核心**：極簡不是缺席，是精準的在場。每個選擇都是宣言。品牌應該讓人「一眼記住，難以複製」。

**視覺 DNA**
- 色彩：一個強烈的品牌色 + 黑白；或全黑白強調排版
- 字體：大膽的 Display 字體作為主角；內文保持克制
- 佈局：大字體、大留白，不懼怕空間
- 特徵：字體即圖形，排版即設計

**最適場景**：品牌發表、產品上市、品牌識別呈現、創意機構介紹

**避免場景**：資訊密集的報告、需要親和感的場景

**提示詞模板**
```
Build studio aesthetic:
- Bold display typeface as hero visual (Druk, Monument, or similar)
- Maximum contrast: one strong brand color vs black/white
- Large type, generous whitespace — type IS the image
- Confident asymmetry, no centering for centering's sake
- Brand statement at display size (80px+), body text minimal
```

## T8 · Locomotive Scroll / Locomotive Studio — 動態排版敘事

**哲學核心**：滾動是敘事媒介，不只是導航機制。頁面的每一幀都是設計決策，視差、速度、顯現時機共同構成品牌體驗。

**視覺 DNA**
- 色彩：深色背景（#0A0A0A、#111111）搭配高飽和 accent 色（亮黃、電藍、螢光綠）；或品牌指定主色大膽鋪陳
- 字體：大型 Display 字體主導（Druk Wide、Monument Extended、Neue Haas Grotesk Display）；搭配 tracking 動畫與 clip 揭示
- 佈局：全高 hero section、文字與影像交錯出現、滾動進度驅動元素位移
- 特徵：smooth scroll 曲線緩動、水平滾動段落、parallax 多層次、文字逐字或逐行進場

**最適場景**：互動式作品集、品牌發表微網站、Agency 自我介紹、產品上市倒數頁

**避免場景**：靜態報告文件、需要快速資訊掃描的工具介面、無法執行 JavaScript 的環境

**提示詞模板**
```
Locomotive Scroll / Locomotive Studio aesthetic:
- Full-height hero with scroll-driven text reveal (clip or translate)
- Dark base (#0A0A0A) with one high-saturation accent color
- Large display typeface (Druk Wide, Monument Extended) at oversized scale
- Layered parallax: background moves at 0.3x, foreground at 1x scroll speed
- Section transitions feel cinematic — elements enter with velocity, settle with easing
- Typography is kinetic: tracking expands, lines split, words stagger on scroll
```

## T9 · Active Theory — 沉浸式 WebGL 敘事

**哲學核心**：數位空間是真實的敘事維度。三維環境、粒子物理、環境光效不是噱頭，是讓品牌訊息與情感直接碰撞觀者感知的媒介。

**視覺 DNA**
- 色彩：極深背景（#000000 或 #080C14）＋ 發光色系（電藍 #00D4FF、琥珀 #FFB800、洋紅 #FF2D78）；ambient gradient 緩慢流動
- 字體：精心挑選的現代 Grotesque（Suisse Int'l、GT America、Neue Haas Grotesk）；在三維空間中保持閱讀性
- 佈局：介面融入敘事環境，UI 元素如同場景中的物件，非覆蓋層
- 特徵：WebGL 粒子系統、即時光源、三維場景轉場、滑鼠互動影響環境物理

**最適場景**：電影 / 遊戲官方網站、科技產品發表、品牌年度回顧微網站、頒獎典禮互動體驗

**避免場景**：純文字內容網站、資訊密集應用、需要快速原型的場景（製作週期與預算極高）、低效能裝置優先的場景

**提示詞模板**
```
Active Theory immersive design language:
- WebGL environment: deep black (#000000) base, ambient gradient shifts slowly
- Particle systems respond to cursor — subtle physics, not gimmicky
- Luminous accent colors (#00D4FF electric blue, #FFB800 amber) as light sources
- 3D space with real-time shadows and environment mapping
- UI elements exist within the scene, not as overlays — interface is world-building
- Suisse Int'l or GT America typefaces; clean against the dark complexity
- Camera moves on scroll — scenes transition like film cuts, not page loads
```

## T10 · Sagmeister & Walsh（現 &Walsh）— 規則破壞，情感挑釁

**哲學核心**：美醜是設計師選擇迴避的幻覺。真正觸動人心的設計必須敢於挑釁、敢於難看、敢於讓觀者不舒服——因為不適才是記憶的起點。

**視覺 DNA**
- 色彩：無規則可循，完全服從概念而非美感邏輯；可以是令人不安的高彩度組合，也可以是刻意骯髒的低飽和
- 字體：手寫體、破損字體、精緻印刷字體的激烈混搭；每個字體選擇都是一個立場宣言
- 佈局：刻意的不對稱、元素越界、文字與影像衝突而非和諧
- 特徵：強烈的人體元素或情感符號直接入侵版面；字體本身成為藝術行為而非信息容器

**最適場景**：藝術展覽視覺、創意機構品牌識別、個人品牌、概念性出版物、前衛廣告

**避免場景**：企業客戶（需要信任感）、醫療 / 法律 / 金融領域、功能性數位工具介面、需要清晰資訊層級的場景

**提示詞模板**
```
Sagmeister & Walsh / &Walsh design provocation:
- Rules are starting points to break deliberately, not follow
- Typeface collisions: pair delicate serif with aggressive hand-lettering
- Layout intentionally destabilized — bleed, overlap, diagonal tension
- Color chosen for emotional disruption, not harmony (clashing neons, muted dirty tones)
- Human body or raw emotional imagery integrated into typography
- Every design choice is a statement, not a service
- Discomfort is a feature; the viewer should feel something, not just read something
```

## T11 · Experimental Jetset — 新現代主義辯證

**哲學核心**：向 1960–70 年代歐陸現代主義致敬，但拒絕懷舊。Helvetica 不是復古選擇，而是一個持續有效的論述系統。符號比裝飾更誠實，結構比情緒更持久。

**視覺 DNA**
- 色彩：紅（#E8192C 或接近）、黑、白三色系統為核心；偶爾引入強調色，但保持審慎克制
- 字體：Helvetica 幾乎是唯一選擇（Neue Helvetica、Helvetica Now）；偶爾搭配等寬字體（Courier）作為技術性對位
- 佈局：嚴格的水平與垂直版式；反對 diagonal 構圖；文字區塊比例精算，視覺重量透過尺寸與位置傳達
- 特徵：符號系統作為視覺語言（箭頭、括號、破折號成為設計元素）；可見的網格邊界有時直接呈現於版面

**最適場景**：文化機構識別（美術館、劇場、音樂廳）、獨立音樂廠牌視覺、展覽設計、學術 / 藝術出版物

**避免場景**：需要溫暖感與親和力的品牌、多色彩需求的場景、數位互動重度依賴的產品介面、需要視覺上「令人興奮」的商業場景

**提示詞模板**
```
Experimental Jetset / neo-modernist graphic design:
- Helvetica Neue or Helvetica Now as primary typeface (Futura or Univers as secondary if needed)
- Tricolor system: red (#E8192C), black, white — introduce additional color only with clear reason
- Strict horizontal and vertical composition only — no diagonals
- Symbols as language: arrows, brackets, em-dashes as primary visual elements
- Mathematical text-block proportions, whitespace calculated not intuited
- Grid is visible or strongly implied — structure is the aesthetic
- References 1960–70s European modernism through contemporary eyes, not nostalgia
```
