# 簡報設計規則

> 適用：幻燈片、PPT、Deck、投影片、發表用簡報。

---

## 開工前確認清單

```
開始製作簡報前，確認幾件事：

1. 頁數與結構：幾頁？有大綱了嗎？
2. 使用場景：現場演講 / 自閱 PDF / 線上傳閱？
3. 時長：幾分鐘的簡報？（估算節奏）
4. 品牌規範：有 logo 或色彩規範嗎？
```

---

## 固定規格

| 項目 | 規格 |
|------|------|
| 尺寸 | 1920 × 1080px（16:9） |
| 引擎 | `assets/deck_stage.js`（鍵盤 ← → 翻頁） |
| 字體最小值 | 內文 24px，Caption 18px |
| 行距 | 1.4–1.6 |

---

## 頁面類型與版型

### 封面頁
- 主標題（Display size，60–96px）
- 副標題 / 日期 / 單位（24–32px）
- 一個視覺主角（圖片、大色塊、或純排版）

### 議程 / 目錄頁
- 清單式，編號清楚
- 每項可加簡短描述（選用）

### 內容頁
- 標題 + 主體（文字 / 圖表 / 圖片）
- 遵循「一頁一個核心訊息」原則
- 內文不超過 5 個 bullet，每個 bullet 不超過 15 字

### 數據頁
- 大數字作為視覺主角（80–120px）
- 輔助說明文字保持克制
- 圖表用 Chart.js inline 或純 CSS/SVG

### 引言 / 強調頁
- 全版底色或大圖
- 一句話，字號 48–72px

### 結尾頁
- Thank You / Q&A / 行動呼籲（CTA）
- 聯絡資訊、logo

## 排版規則

```
字體層級（同一頁面最多 3 層）：
- Display：封面標題、章節標題
- Heading：頁面標題（32–48px）
- Body：內文（24–28px）
- Caption：來源、備注（18px）

對齊：
- 同一頁面的文字元素統一對齊方式（全靠左或全置中，不混用）
- 圖表 / 圖片：留邊距至少 80px

邊距（建議）：
- 四邊 80–120px
- 標題與內容間距：40–60px
```

---

## 動畫 / 轉場

- 預設：無動畫（靜態），利於 PDF 導出
- 需要動畫時：用 CSS `@keyframes`，避免 JavaScript 複雜動畫
- 每頁切換：`deck_stage.js` 內建的 fade（0.3s ease）

---

## 演講者模式

使用 `deck_stage.js` 時，支援按 `S` 鍵開啟 Speaker Notes 視窗（副螢幕用）：

```html
<section class="slide" data-notes="這頁重點：強調成本降低 40%，舉實際案例佐證">
  <!-- slide content -->
</section>
```

---

## 常見錯誤

- 每頁放太多文字（大於 80 字要拆頁）
- 字型混用超過 2 種
- 色彩超過 3 個（品牌色 + 強調色 + 中性色即可）
- 圖表沒有標題或來源標注
- 全部頁面用同一版型（缺乏節奏感）
