## R1 · Anti-AI Crafting — 人手感美學

**哲學核心**：2026 年 AI 生成的視覺已氾濫。刻意保留人工痕跡——掃描線、紙張紋理、拼貼錯位——才是讓作品被記住的方式。「看起來被做出來」比「看起來被生成」更有價值。

**視覺 DNA**
- 色彩：略微髒的色調（非純色，帶紙張感的 offset）；印刷感
- 字體：手寫體、打字機體、略有不完美的排版
- 佈局：刻意的不對齊、重疊、裁切；像拼貼而非網格
- 質感：掃描紙張紋理（grain）、墨水暈染、折痕、貼紙感

**最適場景**：創意機構作品集、藝術項目、獨立音樂品牌、反主流文化產品

**避免場景**：需要嚴謹、信任感的場景（醫療、金融、法律）

**提示詞模板**
```
Anti-AI Crafting aesthetic:
- Paper texture overlays (grain: 15-25% opacity noise)
- Slightly off-register colors — print misalignment feel
- Typewriter or hand-lettered fonts mixed with system type
- Collage-style overlapping elements, intentional crop
- Colors: warm off-white (#F5F0E8), ink black (#1A1A18), muted accents
- Nothing perfectly centered or perfectly aligned
```

## R2 · Dopamine Design — 高飽和快樂美學

**哲學核心**：設計應該讓人「看到就開心」。高飽和度、大膽的色彩對比、圓滾滾的形狀——直接攻擊感官愉悅，不繞彎子。

**視覺 DNA**
- 色彩：高飽和、強對比；螢光黃 + 電藍 + 珊瑚紅同時出現
- 字體：圓角胖體（Rounded sans）、大號、充滿能量
- 佈局：密集但有韻律；大色塊切割畫面
- 質感：亮面、漸層、3D 泡泡感、光澤

**最適場景**：消費品發表、年輕族群 App、社群媒體素材、節慶活動

**避免場景**：需要專業沉穩感的場景；需要長時間閱讀的內容

**提示詞模板**
```
Dopamine Design / Neo-Maximalist Bright:
- Saturated palette: electric blue (#0066FF), coral (#FF4D4D), acid yellow (#FFE600)
- Rounded bold typefaces (Nunito, Poppins Rounded, or custom)
- Large color blocks as layout structure
- 3D glossy elements, soft shadows with color
- Everything feels bouncy, friendly, energetic
- Dense but rhythmic composition
```

## R3 · Retrofuturism / Y2K Revival

**哲學核心**：早期網路的樂觀主義 + 90 年代科幻電影的未來想像。鉻金屬、像素、霓虹——那個「科技還是夢想」的年代，用現代技術重現。

**視覺 DNA**
- 色彩：黑底 + 霓虹（Neon pink、Electric cyan、Acid green）；或銀灰鉻色調
- 字體：像素字體、工業等線體；或 Eurostile、Bank Gothic 等科幻感字型
- 佈局：不規則網格；斜切分割；CRT 掃描線效果
- 質感：鉻金屬光澤、玻璃感、像素化邊緣、舊螢幕雜訊

**最適場景**：科技品牌發表、音樂 / 遊戲產業、NFT / Web3 相關、懷舊行銷活動

**避免場景**：需要現代簡潔感的場景；企業客戶 / 機構場景

**提示詞模板**
```
Retrofuturism / Y2K aesthetic:
- Dark base (#050510 or #0A0A0A) with neon accents
- Neon: #FF00FF magenta, #00FFFF cyan, #00FF41 matrix green
- Chrome / metallic gradients on key elements
- Pixel or bitmap fonts for display, Eurostile for body
- CRT scanline overlay (subtle repeating horizontal lines)
- Lens flare, glow effects, retro sci-fi UI panels
```

## R4 · Maximalism — 控制的混沌

**哲學核心**：多即是多。拒絕極簡的霸權，擁抱豐盛、疊層、碰撞。但「最大主義」不是亂——是每個元素都有意圖的密集。

**視覺 DNA**
- 色彩：多色、不怕衝突；深底配明亮；色彩疊加製造深度
- 字體：多種字體混用；大小對比誇張；可以溢出邊界
- 佈局：疊層、重疊、打破網格；內容密度高
- 質感：圖案、插圖、攝影、文字混合疊加

**最適場景**：時尚品牌、藝術 / 文化機構、雜誌式排版、個性強烈的品牌

**避免場景**：需要快速資訊獲取的介面；企業正式場合

**提示詞模板**
```
Maximalism / Controlled Chaos:
- Rich layering: photography + illustration + type all coexist
- Bold color collisions — no single dominant hue
- Multiple typefaces (max 3-4) at dramatically different scales
- Elements overlap and bleed out of bounds intentionally
- Dense composition with visual rhythm (not random noise)
- Pattern or texture fills empty spaces
```

## R5 · Tactile Organic — 觸感自然主義

**哲學核心**：螢幕疲勞時代的解藥。自然材質感、泥土色調、手作溫度——讓數位設計「感覺可以被觸摸」，帶來平靜與信任。

**視覺 DNA**
- 色彩：大地色系（赭石、鼠尾草綠、奶油白、深棕）；低飽和
- 字體：人文主義無襯線體或細明體；有機感
- 佈局：非對稱但平衡；有「呼吸感」的留白
- 質感：布料紋理、石頭顆粒感、木材肌理；手繪插圖點綴

**最適場景**：食品 / 飲料品牌、健康 / wellness 產品、永續品牌、手作工藝

**避免場景**：科技感強烈的場景；需要精確、冷靜的場景

**提示詞模板**
```
Tactile Organic / Natural Warmth:
- Earth palette: #D4A574 terracotta, #8B9467 sage, #F5EDD6 cream, #3D2B1F dark brown
- Humanist sans-serif (Freight, Lato, or Source Sans)
- Paper or linen texture overlays (subtle, 10-20% opacity)
- Hand-drawn botanical or organic shape accents
- Rounded, soft — no sharp angles unless intentional
- Warm off-white backgrounds, never pure white
```

## R6 · Bento Box — 模組卡片系統

**哲學核心**：Apple WWDC 發表會發揚光大的佈局語言。將功能 / 資訊切分為大小不一的卡片格，每格自成一個完整的視覺單位，整體又構成有韻律的畫面。

**視覺 DNA**
- 色彩：深色底（#1C1C1E 或 #0F0F10）+ 各格用不同強調色；或淺色底 + 灰階卡片
- 字體：SF Pro 或接近的現代等線體；大號 Feature text 在卡片內
- 佈局：CSS Grid 主導；卡片有明確圓角（12–24px）；格子大小有對比
- 質感：毛玻璃（frosted glass）、精緻陰影、微邊框

**最適場景**：產品功能介紹、App 發表、科技品牌官網、功能對比頁

**避免場景**：需要連貫敘事的場景；文字量大的場景

**提示詞模板**
```
Bento Box layout system:
- CSS Grid with varying cell sizes (1×1, 1×2, 2×1, 2×2 spans)
- Dark base (#1C1C1E) or light (#F5F5F7), card radius 16-24px
- Each card = one feature, one stat, or one visual
- Frosted glass cards: rgba(255,255,255,0.06) + backdrop-filter blur
- SF Pro or Inter, large feature numbers/text as card hero
- Subtle inner glow or 1px border on cards
```

## R7 · Intentional Imperfection — 刻意的不完美

**哲學核心**：2026 年的創作者反演算法、反精緻、反「AI 可以生成」的美學。刻意讓設計感覺不完美——錯位的字、歪斜的框、手繪的箭頭——讓人感受到真實的人在背後。

**視覺 DNA**
- 色彩：不飽和、帶灰度；像被時間洗過的色調
- 字體：手寫感、略歪斜；或用排版錯位製造張力
- 佈局：刻意打破對稱；元素略微旋轉（±2–5°）；留白不均衡
- 質感：手繪線條、草圖感、便利貼、橡皮擦痕跡

**最適場景**：個人作品集、獨立創作者品牌、藝術項目、反主流設計宣言

**避免場景**：需要信任感、精確感的場景；任何機構或商業正式場合

**提示詞模板**
```
Intentional Imperfection aesthetic:
- Muted, slightly faded palette — as if sun-bleached
- Hand-drawn annotations, arrows, underlines (SVG paths with jitter)
- Elements rotated ±1-4 degrees, never perfectly level
- Mixed typefaces: a formal one + a handwritten one
- Asymmetric margins, uneven whitespace
- Sketch-like borders instead of perfect rectangles
```

## R8 · Neo-Brutalism — 新粗獷主義

**哲學核心**：拒絕 UI 的「精緻包裝」。厚重黑邊框、純色塊、raw HTML 感——把 web 的底層材料直接暴露出來作為美學。不是粗糙，是刻意選擇的「不假裝柔順」。與 Maximalism 的區別在於：Maximalism 是「多而豐盛」，Neo-Brutalism 是「少而暴力」。

**視覺 DNA**
- 色彩：高飽和純色（黃 / 紅 / 白 / 黑）；無漸層；色塊以厚黑邊框分隔
- 字體：最重字重的無襯線體（Black / ExtraBold）；或等寬字體（monospace）
- 佈局：`border: 3–5px solid #000`；offset box-shadow（`4–6px 4–6px 0 #000`，無模糊）；故意的視覺重量失衡
- 質感：無質感。平面、無陰影羽化、無漸層、無毛玻璃

**最適場景**：新創品牌、設計機構作品集、軟體產品 landing page、個人作品集（強個性版）

**避免場景**：醫療、金融、政府；任何需要信任感或細膩度的場景

**提示詞模板**
```
Neo-Brutalism aesthetic:
- Solid thick borders: border: 3-5px solid #000
- Card shadow: box-shadow: 4-6px 4-6px 0 #000 (hard offset, zero blur)
- High saturation solids: #FFE600 yellow, #FF3333 red, #FFFFFF, #000000
- Heavy weight sans-serif (Black/ExtraBold) — Syne, Space Grotesk, Impact
- Zero gradients, zero blur, zero frosted glass
- Asymmetric layout, intentional weight imbalance
- Interactive elements: thick border + offset shadow that collapses on hover/press
```

## R9 · Glassmorphism — 液態毛玻璃

**哲學核心**：Apple Vision OS 和 Apple Intelligence 發展出的「液態分層」美學。半透明的毛玻璃層漂浮在豐富背景之上，資訊有深度感而不沉重。2025–2026 年在 iOS App、AI 產品介面、高端 Web 應用中已是主流視覺語言。

**視覺 DNA**
- 色彩：背景豐富（深色漸層 / 彩色模糊照片）；前景用半透明白膜壓在上面
- 字體：細到中等粗細；SF Pro 或 Geist；配 backdrop-filter 的清爽通透感
- 佈局：卡片浮在空間中；三層深度（背景、中層毛玻璃、前景內容）；層次感明確
- 質感：`backdrop-filter: blur(12–24px)`；`rgba(255,255,255,0.08–0.15)`；精緻的 1px 邊框 `rgba(255,255,255,0.2)`；微雜訊防止浮離感

**最適場景**：iOS App 介面、Vision OS 風格、AI 產品 UI、dark mode 為主的 SaaS 登陸頁

**避免場景**：需要高可及性的場景（backdrop-filter 增加認知負擔）；對比度要求嚴格的場合

**提示詞模板**
```
Glassmorphism / Liquid Glass aesthetic:
- Rich dark background: deep gradient (#0A0A1A → #1A0A3A) or blurred photo
- Cards: background rgba(255,255,255,0.08), backdrop-filter blur(16-24px)
- Border: 1px solid rgba(255,255,255,0.18)
- Box-shadow: 0 8px 32px rgba(0,0,0,0.3), inset 0 1px 0 rgba(255,255,255,0.12)
- Text: white or near-white (#F0F0F0), letter-spacing: 0.01em
- Three depth levels: background → frosted cards → foreground content
- Subtle noise texture (1-2% opacity SVG filter) to anchor floating elements
```
