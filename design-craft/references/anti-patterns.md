# 禁止事項 — AI 設計陷阱清單

> 這些模式讓設計「一眼看出是 AI 做的」。每次動手前過一遍。

---

## 視覺 Anti-patterns

### 色彩
- 禁止：預設紫色 / 藍色漸層（#667EEA → #764BA2 這類）
- 禁止：沒有設計原因的漸層（漸層應有明確的哲學理由）
- 禁止：超過 3 個主色（品牌色 + 強調色 + 中性色已足夠）
- 禁止：純灰 `#888888` 作為文字色（WCAG AA 對比度不足）

### 字體
- 禁止：同一頁面超過 2 種字體家族
- 禁止：用 Inter 做 Display 字體（Inter 是內文字體，不是主視覺）
- 禁止：所有文字大小相近（缺乏層級）
- 禁止：行高 < 1.4（內文不可讀）

### 版面
- 禁止：所有東西置中對齊（全置中是沒有決策的對齊）
- 禁止：左側有色彩 border accent 的卡片（最氾濫的 AI UI 模式）
- 禁止：圓角 + 陰影卡片的無差別堆疊（每張卡片都一樣是沒有層級的）
- 禁止：大量 emoji 作為圖示（特別是 ✅ 📌 🎯 這類辦公室 emoji）

### 圖示
- 禁止：用 SVG 手畫人臉 / 人物（永遠畫不好，用真實圖片或留空）
- 禁止：Heroicons / Feather Icons 的無差別濫用（考慮是否真的需要）
- 禁止：大量圖示但每個圖示含義模糊

---

## 內容 Anti-patterns

- 禁止：用「Lorem ipsum」作為最終交付的文案佔位（要用 `data-placeholder` 標記）
- 禁止：自行發明假資料（如造假的統計數字）而不標記為「示例數據」
- 禁止：涉及真實品牌時靠記憶猜色值 / logo 形狀
- 禁止：承諾外部圖片 URL 而不驗證其存在（圖片 404 是常見問題）

---

## 行為 Anti-patterns

- 禁止：添加表面化的 ARIA 標記而不確認正確性（例：`<div onclick>` 沒加 `tabindex="0"`，或 `aria-hidden="true"` 元素卻有鍵盤焦點）
- 禁止：不問就直接做一個完整版本（除非任務極度明確）
- 禁止：一次呈現超過 3 個方向選項（超過讓使用者選擇疲勞）
- 禁止：在使用者選定方向前開始寫大量程式碼
- 禁止：完成後不驗證（一定要在瀏覽器或 Playwright 看過）

---

## 風格例外條款

以下規則在**明確選定 Trending 風格**後可有意圖地突破。突破前提：已選定風格，不是「不知道規則」。

| 規則 | 例外風格 | 原因 |
|------|---------|------|
| 超過 3 個主色 | R2 Dopamine、R4 Maximalism | 高色彩複雜度是風格核心 |
| 同頁超過 2 種字體 | R4 Maximalism | 字體碰撞即美學主張 |
| 避免無理由漸層 | R3 Retrofuturism、R9 Glassmorphism | 鉻金屬光澤 / 毛玻璃是風格 DNA |
| 避免全置中 | R2 Dopamine | 慶典式置中作為設計 statement（仍需決策，非無意識） |
| 左側 border accent 卡片 | R4 Maximalism | 在密集疊層脈絡下可存在，但仍應有差異化 |

## 快速自檢（交付前）

```
□ 色彩：有設計原因嗎？不是預設漸層？
□ 字體：不超過 2 種？有明確層級？
□ 對齊：不是全部置中？
□ 卡片：不是左側 border accent 的複製貼上？
□ 圖示：真的需要嗎？
□ 資料：有 placeholder 標記嗎？
□ 品牌：如果有品牌，資產是確認過的嗎？
□ 驗證：有在瀏覽器開過嗎？
```
