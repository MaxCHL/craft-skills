# 方向引導流程

> 當使用者需求模糊，或沒有指定風格時使用。
> 目標：用最少的問題，找到最精準的設計方向。

---

## 何時進入此流程

- 使用者說「幫我設計」、「做個好看的」、「不知道要什麼風格」
- 任務描述無法歸類到具體輸出類型
- 使用者給了主題但沒有說輸出形式

---

## 三個釐清問題（一次問完，不分多輪）

```
在開始之前，我需要確認三件事：

1. **輸出形式**
   原型 / 幻燈片 / 資訊圖 / 動畫 / 其他？

2. **情境與受眾**
   這個設計給誰看？在什麼場合使用？
   （例：投資人簡報 / 對外官網 / 內部工具 / 社群素材）

3. **風格傾向**（擇一）
   - 穩重專業（長期耐看，企業感）
   - 當下流行（有時代感，吸引年輕受眾）
   - 不確定（我推薦兩個方向讓你選）
```

---

## 收到回答後的處理邏輯

### 有明確輸出形式 + 有風格傾向
→ 直接從對應風格庫選 2 個差異化方向，各一句話描述氣質，讓使用者選定後執行

### 有明確輸出形式 + 無風格傾向
→ 從 Timeless 各選 1 個、Trending 各選 1 個，共 2 個方向呈現：
```
方向 A（穩重）：[風格名] — [一句話氣質描述]
方向 B（流行）：[風格名] — [一句話氣質描述]
```

### 輸出形式不明
→ 根據主題推斷最合理的形式，說明推斷理由，請使用者確認後繼續

---

## 方向呈現格式

選定輸出形式與風格層後，推薦 2–3 個方向，格式如下：

```
這個任務我推薦以下方向，請選一個：

**方向 A · [風格名]**
氣質：[用一句話描述視覺感受，讓使用者能想像]
代表色調：[2–3 個顏色描述]
適合原因：[為什麼這個風格適合這個任務]

**方向 B · [風格名]**
氣質：[...]
代表色調：[...]
適合原因：[...]

選好後我立刻開始。
```

---

## 使用者選定後

1. 載入對應的輸出類型 reference（prototype / slides / infographic）
2. 載入選定風格的完整提示詞模板
3. 開始製作，先展示骨架或 wireframe 層，再填充細節
