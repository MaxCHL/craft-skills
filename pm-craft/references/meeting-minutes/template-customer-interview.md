# Template — 客戶 / 使用者訪談

關鍵詞觸發：訪談、interview、痛點、使用情境、目前怎麼做、JTBD、persona、user research

---

## 此類會議的特徵

- 通常 1 位訪談者 + 1 位受訪者（有時加 note taker / observer）
- **verbatim quote 極其重要** — 客戶原話 = 產品決策的證據
- 不是會議「決策」，是資訊蒐集
- Decisions 可能為空；重點在 Insights + Quotes
- 通常會做多場訪談後彙整，所以單場紀錄需可被「聚合」

---

## 預設訪談結構（無腳本時的推測）

1. **背景介紹** — 受訪者角色、規模、工作內容
2. **現況流程** — 目前是怎麼做這件事的
3. **痛點挖掘** — 卡在哪、為什麼
4. **替代方案** — 試過什麼、為什麼不夠好
5. **期待解法** — 理想中要長怎樣
6. **價格訊號** — 願意付多少（若有問）

### 2. JTBD 六要素

每個討論主題嘗試填滿：

```markdown
**JTBD: 會員續約追蹤**

| 維度 | 內容 |
|------|------|
| Situation | 會員預約完會議室，要記錄並提醒下次使用 |
| Trigger | 月租到期前 2 週若無續約紀錄，需主動聯繫 |
| Motivation | 維持會員續約率、會員滿意度 |
| Workaround | 目前用 Excel + Line 群組手動提醒 |
| Pain | 漏聯絡的會員約 15% [推測，受訪者口述]，導致續約率下降 |
| Expected Outcome | 自動提醒，不需櫃檯逐一打電話 |
```

### 3. 痛點優先級

訪談中提到的痛點要排序：

```markdown
**痛點優先級（受訪者觀點）**

| Rank | 痛點 | 頻率 | 嚴重度 | Verbatim |
|------|------|------|--------|----------|
| 1 | 續約提醒手動 | 每天 | 高 | 「我們櫃檯每天花 1 小時打電話，這成本超高」 |
| 2 | 跨分店紀錄不流通 | 每週 | 中 | 「會員換分店，舊紀錄就丟了」 |
| 3 | 月租 vs 單次計費混淆 | 每週 | 中 | 「老會員常搞不清楚這次是月租額度還是單次計費」 |
```

### 4. 替代方案分析

```markdown
**目前的替代方案**

| 方案 | 怎麼用 | 為什麼不夠好 |
|------|--------|-------------|
| Excel | 手動輸入預約日期 | 容易忘、無提醒、無歷史 |
| Line 群組 | 櫃檯發提醒訊息 | 被洗版、會員不一定看 |
| 紙本 | 櫃檯貼便利貼 | 找不到、容易掉 |
```

### 5. 願付價格訊號

```markdown
**價格訊號**

- 受訪者主動提及：「如果一個月幾千塊，我可以接受」 [推測 NT$3,000-5,000/月]
- 比較基準：目前櫃檯工時成本 ~ NT$8,000/月（受訪者估算）
- 拒絕區間：> NT$10,000/月「就不如自己請工讀生」
```

### 6. Verbatim Quotes（必抓 3-5 句）

```markdown
**關鍵原話**

> 「我們櫃檯每天花 1 小時打電話提醒續約，這成本超高，而且常常聯絡不到。」
> — 受訪者 #03，談到目前痛點

> 「月租紀錄 vs 單次計費紀錄分開，老會員常搞不清楚這次是哪種。」
> — 受訪者 #03，談到會員體驗

> 「如果一個月幾千塊我可以接受，但超過一萬就不如自己請工讀生。」
> — 受訪者 #03，談到價格容忍度
```

## 客戶訪談紀錄的特別準則

1. **Verbatim 至少 3 句** — 客戶原話是產品決策的證據，比歸納更有力
2. **Decisions 區可空** — 訪談的產出是 Insights，不是決議
3. **Persona card 必填** — 後續聚合分析需要對齊
4. **痛點要排序** — 受訪者自己排，不要訪談者代排
5. **價格訊號要區分** — 願付區間 vs 拒絕線，兩個都記
6. **Insights 段給 PM** — 訪談者的延伸觀察與訪談原話分開

---

## 不要做的事

- ❌ 把訪談者的提問當「決議」
- ❌ 自己腦補 persona 細節（受訪者沒講就 `[需確認]`）
- ❌ 把 leading question 的答案當客戶真實意見
- ❌ 過度濃縮客戶原話（verbatim 就是要保留語感）
- ❌ 把 1 個訪談的洞察當「群體真理」（在 Insights 段標「N=1，待擴大樣本」）
